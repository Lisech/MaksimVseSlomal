# Тестирование IDEF0 Editor

## Единый файл запуска всех тестов

Все функции тестирования объединены в один самодостаточный файл:

**`run_all_tests.py`** - включает автоматические тесты и ручное тестирование

## Запуск

```bash
python IDEF0_editor/tests/run_all_tests.py
```

или из директории `IDEF0_editor`:

```bash
python tests/run_all_tests.py
```

## Структура тестов

```
tests/
├── run_all_tests.py          # Единый файл запуска всех тестов
├── manual/
│   └── MANUAL_TESTING.md     # Руководство по ручному тестированию
├── unit/                     # Unit тесты
│   ├── __init__.py
│   ├── test_models.py
│   └── test_app_functions.py
├── integration/              # Интеграционные тесты
│   ├── __init__.py
│   └── test_app_integration.py
└── automated/                # Автоматические UI тесты
    ├── __init__.py
    └── test_ui_automation.py
```

## Возможности

### Автоматические тесты

1. **Unit тесты** - тестирование отдельных компонентов (модели Block, Arrow)
2. **Интеграционные тесты** - тестирование взаимодействия компонентов
3. **Автоматические UI тесты** - программное тестирование интерфейса

### Ручное тестирование

- Список всех тестов из `MANUAL_TESTING.md`
- Просмотр инструкций для каждого теста
- Отметка результатов (пройден/провален)
- Сохранение результатов в JSON

## Интерфейс

Приложение имеет две вкладки:

1. **Автоматические тесты** - запуск и просмотр результатов автоматических тестов
2. **Ручное тестирование** - работа с ручными тестами

### Автоматические тесты

- Кнопки запуска отдельных типов тестов или всех сразу
- Область вывода результатов в реальном времени
- Статус бар и прогресс бар
- Статистика выполнения тестов
- Сохранение результатов в файл

### Ручное тестирование

- Список тестов слева с цветовой индикацией:
  - ✓ Зеленый - тест пройден
  - ✗ Красный - тест провален
  - ○ Серый - тест не протестирован
- Область инструкций справа
- Кнопки для отметки результатов
- Статистика ручного тестирования

## Требования

- Python 3.7+
- Tkinter (обычно входит в стандартную поставку Python)
- Модули приложения (app.py, models.py, properties.py, styles.py)

## Файлы результатов

- **Автоматические тесты**: сохраняются в текстовый файл через диалог сохранения
- **Ручное тестирование**: сохраняются в `tests/manual_test_results.json`

## Особенности

- ✅ Один файл - все функции тестирования
- ✅ Самодостаточный - не требует дополнительных файлов
- ✅ Встроенный парсер ручных тестов
- ✅ Полный функционал в одном месте
