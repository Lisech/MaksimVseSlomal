# Запуск тестирования

## Единый файл для всех тестов

Все функции тестирования объединены в один файл:

**`run_all_tests.py`**

## Быстрый запуск

```bash
python tests/run_all_tests.py
```

## Что включено

✅ Автоматические тесты (unit, integration, automated)  
✅ Ручное тестирование с интерфейсом  
✅ Парсер ручных тестов (встроенный)  
✅ Сохранение и загрузка результатов  

## Структура

- `run_all_tests.py` - единый файл запуска (все функции здесь)
- `manual/MANUAL_TESTING.md` - руководство по ручному тестированию
- `unit/`, `integration/`, `automated/` - директории с тестовыми файлами

Все остальные файлы тестирования удалены - используйте только `run_all_tests.py`!
