# Руководство по ручному тестированию IDEF0 Editor

## Общая информация

Этот документ содержит подробные инструкции для ручного тестирования всех функций IDEF0 Editor.

## Подготовка к тестированию

1. Запустите приложение: `python main.py` или `main.exe`
2. Убедитесь, что окно приложения открылось полностью
3. Проверьте, что все панели видны (левая панель инструментов, холст, правая панель свойств)

---

## 1. Тестирование создания блоков

### 1.1 Создание блока из панели инструментов

**Шаги:**
1. Нажмите на кнопку "Блок" в левой панели инструментов
2. Кликните на холсте в любом месте
3. Проверьте, что блок появился на холсте

**Ожидаемый результат:**
- Блок создан с размерами по умолчанию (150x80)
- Блок имеет стандартный цвет заливки
- Блок имеет текст "Входит название..."
- Блок выбран (подсвечен)

### 1.2 Создание блока перетаскиванием

**Шаги:**
1. Нажмите и удерживайте кнопку "Блок" в левой панели
2. Перетащите на холст
3. Отпустите кнопку мыши

**Ожидаемый результат:**
- Блок создан в месте отпускания мыши
- Блок выбран

### 1.3 Создание нескольких блоков

**Шаги:**
1. Создайте 5 блоков в разных местах холста
2. Проверьте, что каждый блок имеет уникальный ID

**Ожидаемый результат:**
- Все блоки созданы успешно
- Блоки не перекрываются (если не перетаскивались)
- Каждый блок независим

---

## 2. Тестирование редактирования блоков

### 2.1 Выбор блока

**Шаги:**
1. Кликните на блок на холсте
2. Проверьте панель свойств справа

**Ожидаемый результат:**
- Блок выделен (подсвечен границей)
- Появились маркеры изменения размера на углах блока
- Панель свойств показывает свойства блока
- Кнопки действий (удалить, копировать) видны

### 2.2 Изменение названия блока

**Шаги:**
1. Выберите блок
2. В панели свойств в поле "Название" введите "Тестовый блок"
3. Нажмите Enter или кликните вне поля

**Ожидаемый результат:**
- Текст на блоке обновился
- Текст автоматически переносится, если не помещается
- Длинный текст обрезается до 100 символов

### 2.3 Изменение кода блока

**Шаги:**
1. Выберите блок
2. В поле "Код" введите "A1"
3. Нажмите Enter

**Ожидаемый результат:**
- Код блока обновлен (визуально не отображается, но сохраняется)

### 2.4 Изменение позиции блока

**Шаги:**
1. Выберите блок
2. Перетащите блок в другое место
3. Отпустите кнопку мыши

**Ожидаемый результат:**
- Блок переместился в новое место
- Блок остался выбранным
- Стрелки, соединенные с блоком, обновились

### 2.5 Изменение размера блока

**Шаги:**
1. Выберите блок
2. Перетащите угловой маркер изменения размера
3. Отпустите кнопку мыши

**Ожидаемый результат:**
- Размер блока изменился
- Маркеры остались на углах блока
- Минимальный размер соблюден (50x30)
- Текст автоматически переформатировался

### 2.6 Изменение цвета блока

**Шаги:**
1. Выберите блок
2. В панели свойств выберите другой цвет из палитры
3. Кликните на цветной квадрат

**Ожидаемый результат:**
- Цвет заливки блока изменился
- Изменение применено сразу

### 2.7 Изменение толщины границы

**Шаги:**
1. Выберите блок
2. В панели свойств используйте кнопки +/- для толщины границы
3. Проверьте результат

**Ожидаемый результат:**
- Толщина границы изменяется
- Минимальная толщина: 1px, максимальная: 10px

## 3. Тестирование удаления блоков

### 3.1 Удаление через кнопку

**Шаги:**
1. Выберите блок
2. Нажмите кнопку "Удалить" (корзина) на блоке
3. Подтвердите удаление (если требуется)

**Ожидаемый результат:**
- Блок удален с холста
- Стрелки, соединенные с блоком, также удалены или отключены

### 3.2 Удаление через горячую клавишу

**Шаги:**
1. Выберите блок
2. Нажмите клавишу Delete или Del

**Ожидаемый результат:**
- Блок удален
- Действие можно отменить через Ctrl+Z

### 3.3 Удаление нескольких блоков

**Шаги:**
1. Создайте 3 блока
2. Удалите их по очереди
3. Проверьте, что все удалены

**Ожидаемый результат:**
- Все блоки удалены
- Холст пуст

---

## 4. Тестирование создания стрелок

### 4.1 Создание стрелки между блоками

**Шаги:**
1. Создайте 2 блока
2. Нажмите кнопку "Стрелка" в панели инструментов
3. Кликните на первом блоке (начало стрелки)
4. Кликните на втором блоке (конец стрелки)

**Ожидаемый результат:**
- Стрелка создана между блоками
- Стрелка прикреплена к блокам
- Стрелка имеет наконечник на конце

### 4.2 Создание стрелки от блока к свободной точке

**Шаги:**
1. Создайте блок
2. Включите режим рисования стрелок
3. Кликните на блоке
4. Кликните на пустом месте холста

**Ожидаемый результат:**
- Стрелка создана от блока к свободной точке
- Стрелка прикреплена к блоку только с одной стороны

### 4.3 Создание свободной стрелки

**Шаги:**
1. Включите режим рисования стрелок
2. Кликните на пустом месте холста
3. Кликните на другом пустом месте

**Ожидаемый результат:**
- Стрелка создана между двумя свободными точками
- Стрелка не прикреплена к блокам

### 4.4 Создание изогнутой стрелки

**Шаги:**
1. Создайте стрелку между блоками, расположенными вертикально
2. Перетащите середину стрелки

**Ожидаемый результат:**
- Стрелка изогнулась
- Появилась точка изгиба
- Стрелка сохраняет соединение с блоками

---

## 5. Тестирование редактирования стрелок

### 5.1 Выбор стрелки

**Шаги:**
1. Кликните на стрелку на холсте
2. Проверьте панель свойств

**Ожидаемый результат:**
- Стрелка выделена (толщина увеличена)
- Появились маркеры для перетаскивания концов
- Панель свойств показывает свойства стрелки
- Кнопки действий видны

### 5.2 Изменение цвета стрелки

**Шаги:**
1. Выберите стрелку
2. В панели свойств выберите другой цвет
3. Кликните на цветной квадрат

**Ожидаемый результат:**
- Цвет стрелки изменился
- Текст на стрелке (если есть) также изменил цвет

### 5.3 Изменение толщины стрелки

**Шаги:**
1. Выберите стрелку
2. В панели свойств используйте кнопки +/- для толщины
3. Проверьте результат

**Ожидаемый результат:**
- Толщина стрелки изменяется
- Минимальная толщина: 1px, максимальная: 10px

### 5.4 Изменение стиля стрелки

**Шаги:**
1. Выберите стрелку
2. В панели свойств выберите стиль (solid, dashed, dotted)
3. Проверьте результат

**Ожидаемый результат:**
- Стиль линии изменился
- Изменение применено сразу

### 5.5 Добавление текста на стрелку

**Шаги:**
1. Выберите стрелку
2. В панели свойств в поле "Текст на стрелке" введите "Тест"
3. Нажмите Enter

**Ожидаемый результат:**
- Текст появился на стрелке
- Текст параллелен стрелке
- Текст не пересекается со стрелкой (смещен в сторону)
- Текст имеет обводку противоположного цвета

### 5.6 Перетаскивание концов стрелки

**Шаги:**
1. Выберите стрелку
2. Перетащите маркер начала стрелки
3. Перетащите маркер конца стрелки

**Ожидаемый результат:**
- Концы стрелки перемещаются
- Если перетащить к блоку, стрелка прикрепляется
- Если перетащить от блока, стрелка открепляется

## 6. Тестирование Undo/Redo

### 6.1 Отмена создания блока

**Шаги:**
1. Создайте блок
2. Нажмите Ctrl+Z

**Ожидаемый результат:**
- Блок удален
- Кнопка Redo становится активной

### 6.2 Повтор создания блока

**Шаги:**
1. После отмены создания блока нажмите Ctrl+Y

**Ожидаемый результат:**
- Блок восстановлен
- Блок находится в том же месте

### 6.3 Отмена изменения размера

**Шаги:**
1. Измените размер блока
2. Нажмите Ctrl+Z

**Ожидаемый результат:**
- Размер блока восстановлен
- Позиция восстановлена

### 6.4 Отмена перемещения

**Шаги:**
1. Переместите блок
2. Нажмите Ctrl+Z

**Ожидаемый результат:**
- Блок вернулся на исходное место

### 6.5 Множественные отмены

**Шаги:**
1. Выполните 5 различных действий (создание, перемещение, изменение размера и т.д.)
2. Нажмите Ctrl+Z 5 раз

**Ожидаемый результат:**
- Все действия отменены в обратном порядке
- Максимум 50 действий в истории

---

## 7. Тестирование копирования и вставки

### 7.1 Копирование блока

**Шаги:**
1. Выберите блок
2. Нажмите Ctrl+C или кнопку "Копировать"

**Ожидаемый результат:**
- Блок скопирован в буфер обмена
- Визуально ничего не изменилось

### 7.2 Вставка блока

**Шаги:**
1. После копирования блока нажмите Ctrl+V или кнопку "Вставить"

**Ожидаемый результат:**
- Новый блок создан рядом с оригиналом
- Новый блок имеет новый ID
- Новый блок выбран

### 7.3 Копирование стрелки

**Шаги:**
1. Выберите стрелку
2. Нажмите Ctrl+C

**Ожидаемый результат:**
- Стрелка скопирована в буфер обмена

### 7.4 Вставка стрелки

**Шаги:**
1. После копирования стрелки нажмите Ctrl+V

**Ожидаемый результат:**
- Новая стрелка создана
- Стрелка имеет те же свойства (цвет, толщина, текст)
- Стрелка имеет новый ID

### 7.5 Вырезание блока

**Шаги:**
1. Выберите блок
2. Нажмите Ctrl+X

**Ожидаемый результат:**
- Блок удален с холста
- Блок скопирован в буфер обмена
- Блок можно вставить через Ctrl+V

---

## 8. Тестирование горячих клавиш

### 8.1 Горячие клавиши в режиме выбора

**Шаги:**
1. Убедитесь, что фокус на холсте (не в текстовом поле)
2. Проверьте следующие комбинации:
   - Ctrl+C (копировать)
   - Ctrl+V (вставить)
   - Ctrl+X (вырезать)
   - Ctrl+Z (отменить)
   - Ctrl+Y (повторить)
   - Delete (удалить)

**Ожидаемый результат:**
- Все горячие клавиши работают
- Горячие клавиши не работают, когда фокус в текстовом поле

### 8.2 Горячие клавиши в текстовых полях

**Шаги:**
1. Кликните в поле ввода текста в панели свойств
2. Попробуйте использовать Ctrl+C, Ctrl+V, Ctrl+X

**Ожидаемый результат:**
- Горячие клавиши работают как стандартные команды редактирования текста
- Горячие клавиши приложения не срабатывают

## 9. Тестирование сохранения и загрузки

### 9.1 Сохранение проекта

**Шаги:**
1. Создайте несколько блоков и стрелок
2. Нажмите кнопку "Сохранить" или Ctrl+S
3. Выберите место сохранения и имя файла
4. Сохраните файл

**Ожидаемый результат:**
- Файл сохранен
- Все блоки и стрелки сохранены
- Свойства элементов сохранены

### 9.2 Загрузка проекта

**Шаги:**
1. Нажмите кнопку "Открыть" или Ctrl+O
2. Выберите сохраненный файл
3. Откройте файл

**Ожидаемый результат:**
- Все блоки загружены
- Все стрелки загружены
- Свойства элементов восстановлены
- Позиции элементов восстановлены

### 9.3 Сохранение пустого проекта

**Шаги:**
1. Создайте новый проект (или очистите текущий)
2. Сохраните проект

**Ожидаемый результат:**
- Файл сохранен
- Файл содержит пустые массивы блоков и стрелок

## 13. Тестирование граничных случаев

### 13.1 Создание блока за пределами видимой области

**Шаги:**
1. Увеличьте масштаб
2. Создайте блок за пределами видимой области
3. Уменьшите масштаб

**Ожидаемый результат:**
- Блок создан
- Блок виден при уменьшении масштаба

### 13.2 Создание очень маленького блока

**Шаги:**
1. Создайте блок
2. Уменьшите его размер до минимума (50x30)

**Ожидаемый результат:**
- Блок не может быть меньше минимального размера
- Текст остается читаемым

### 13.3 Создание очень большого блока

**Шаги:**
1. Создайте блок
2. Увеличьте его размер максимально

**Ожидаемый результат:**
- Блок увеличивается без ограничений (или с разумными ограничениями)
- Текст автоматически переносится

### 13.4 Создание стрелки с очень длинным текстом

**Шаги:**
1. Создайте стрелку
2. Добавьте очень длинный текст (200+ символов)

**Ожидаемый результат:**
- Текст отображается (или обрезается с многоточием)
- Текст не перекрывает другие элементы

### 13.5 Удаление блока с множеством стрелок

**Шаги:**
1. Создайте блок
2. Создайте 10 стрелок, соединенных с этим блоком
3. Удалите блок

**Ожидаемый результат:**
- Блок удален
- Все стрелки удалены или отключены
