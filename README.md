# IDEF0 Editor

Редактор диаграмм IDEF0 с современным интерфейсом.

## Сборка exe файла

Для пересборки приложения в exe файл используйте один из скриптов:

### Windows Batch (build.bat)
Просто запустите двойным кликом или из командной строки:
```bash
build.bat
```

### Python скрипт (build.py)
```bash
python build.py
```

### PowerShell скрипт (build.ps1)
```powershell
.\build.ps1
```

Все скрипты автоматически:
- Очищают старые файлы сборки
- Проверяют наличие PyInstaller (устанавливают при необходимости)
- Собирают exe файл из main.spec
- Выводят результат сборки

Готовый exe файл будет находиться в папке `dist/main.exe`

## Требования

- Python 3.x
- PyInstaller (устанавливается автоматически при необходимости)
- Все зависимости из requirements.txt (если есть)

## Структура проекта

- `main.py` - точка входа приложения
- `app.py` - основной класс приложения
- `models.py` - модели данных (Block, Arrow)
- `properties.py` - панель свойств
- `styles.py` - стили и константы
- `main.spec` - конфигурация PyInstaller
- `img/` - папка с иконками
